Gobernanza Abierta

Participación Ciudadana y Gobernanza Colectiva

Esta web y el prompt son un bien común digital. Para garantizar una neutralidad radical, el creador del proyecto no decide en solitario ni actúa como juez: todas las decisiones sobre fuentes, instrucciones y posibles sesgos se debaten y votan en abierto entre la comunidad.

⚖️ Consenso Ciudadano

¿Cómo hacemos real que el creador no decida solo?

🗳️ Explorar debates abiertos y votar ↗

Una herramienta cívica para auditar promesas no puede depender del criterio o ideología de una única persona. Por eso, el repositorio de GitHub funciona como una asamblea ciudadana transparente donde cualquier persona puede entrar, revisar lo que otros han propuesto y ejercer su voto:

💬

1. Opina en los hilos

Entra en cualquier issue abierta y aporta tu perspectiva. No necesitas saber programación: solo razonar con argumentos o experiencias ciudadanas.

👍 / 👎

2. Vota con reacciones

Usa el sistema nativo de reacciones de GitHub. Un 👍 indica respaldo y un 👎 objeción razonada. Las decisiones se toman por consenso del termómetro comunitario.

📜

3. Manda la ley y el BOE

Filtro anti-polarización: un enlace a un registro oficial o boletín del BOE tiene prioridad sobre opiniones de partido o preferencias individuales.

🔍

4. Trazabilidad total

Cada cambio incorporado al prompt cita la issue pública y a las personas que participaron, garantizando que el prompt sea una obra colectiva.

📖 Tutorial: Cómo Participar en 3 Sencillos Pasos

1

Comprueba si ya existe

Revisa el listado de issues abiertas. Si alguien ya propuso la misma idea, dale un 👍 o deja un comentario para sumarle apoyo.

2

Elige la etiqueta adecuada

Usa una de las 4 tarjetas inferiores según se trate de una nueva fuente, una mejora para el prompt, un enlace caído o una sugerencia para la web.

3

Rellena la plantilla y envía

El formulario se abrirá con campos guiados. Completa los datos con enlaces oficiales y pulsa "Submit new issue". La revisaremos e integraremos con rapidez.

Cuándo usar: El texto íntegro del prompt es público. Si al leerlo o usarlo detectas cualquier indicio de sesgo ideológico o una regla que deba afilarse, repórtalo aquí para someterlo a estudio y corregirlo.
